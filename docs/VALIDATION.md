## 尚需空白光盘进行硬件验收

本次开发没有向光盘写入数据。下列项目不能仅由编译、测试或演示证明：

1. 用可读的 ISO 和空白 CD-R/DVD-R，确认刻录、封盘、回读校验均完成；取出后在另一读取设备中挂载并读取文件。
2. 分别验证 DMG、CUE/BIN、TOC 及多轨镜像，包含路径空格与中文文件名。
3. 在不同速度及 BD-R 介质上记录进度、MB/s、倍速、缓冲区容量与保护能力。
4. 关闭校验，确认最终结果明确显示未校验；关闭自动弹出，确认完成后介质保留。
5. 停止写入、校验时停止、拔出光驱、源文件不可读、容量接近上限等故障场景，检查错误和清理完成状态。故障测试只用可舍弃光盘。
6. 确认封盘后的不可追加性符合实际介质能力；不同设备对可重写光盘的关闭行为可能不同。

## 已知平台限制

DiscRecording 的公开状态字典没有缓冲区实时占用率键。若未来必须显示硬件缓冲区填充百分比，需要另行设计并验证 SCSI/MMC 访问方案，处理与刻录引擎的设备独占访问冲突。本版本不会通过未经验证的低层命令干扰刻录。

## 镜像创建功能（2026-09-27）

- SwiftPM 测试共 30 项通过，包含原有刻录测试与新增镜像任务测试。
- 从中文目录、中文及空格文件名、隐藏文件、二进制文件和空目录创建 ISO 9660/Joliet 与 UDF 镜像，实际只读挂载，逐文件比对内容。
- 从只读挂载的虚拟数据盘复制 ISO、CDR 和压缩 DMG；ISO/CDR 长度与设备大小一致且逐字节匹配，三种格式均可挂载并读出原始内容。
- 发现 `hdiutil create -srcdevice -format UDTO` 会省略 ISO 尾部填充，最终实现使用设备总长度逐块读取，避免把仅文件内容相同误判为完整扇区副本。
- 验证重名和路径冲突、Joliet 大文件限制、符号链接拒绝、替换已有目标、失败时保留旧目标、取消进程和清理临时文件。
- 独立应用实例完成“选择测试目录 → 创建 ISO → 用于刻录”界面流程，DiscRecording 成功识别生成的镜像为一条轨道。深色界面的两个新工作模式及光驱忙碌时禁止复制已检查。
- Release 构建成功；Swift 编译无警告。Xcode 输出的 AppIntents 元数据提取跳过提示不影响构建。

开发时原应用正在实际刻录，所以没有重启、替换或停止原实例；新版独立构建于 `build/ImageFeatures/Build/Products/Release/Disc Studio.app`。测试只访问专用临时文件及虚拟镜像设备，未复制正在使用的物理光盘。
